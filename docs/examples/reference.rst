==========
Referência
==========

Tabela de opções disponíveis em ``html_theme_options``.

.. list-table::
   :header-rows: 1

   * - Opção
     - Tipo
     - Descrição
   * - ``primary_color``
     - String
     - Cor primária em hexadecimal (ex: ``#0c4b33``)
   * - ``secondary_color``
     - String
     - Cor secundária em hexadecimal (ex: ``#44b78b``)
