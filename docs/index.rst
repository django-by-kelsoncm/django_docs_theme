Visão Geral
------------

O ``django-docs-theme`` foi desenvolvido para permitir que desenvolvedores Django e organizações no GitHub mantenham um padrão visual limpo, profissional e coeso em todas as suas documentações.

Principais Recursos
-------------------

- **Design Institucional Django**: Verde institucional (`#0c4b33`), suporte a badges e admonitions estilizados.
- **Dark Mode Nativo**: Alternância entre temas claro e escuro com salvamento no ``localStorage``.
- **Blocos de Código Interativos**: Botão para copiar código em um clique.
- **Integração com GitHub**: Link de edição direta no GitHub e links sociais.
- **Automação CI/CD**: Configuração pronta para GitHub Workflows, publicação no PyPI via Trusted Publishing e testes locais com ``act``.
